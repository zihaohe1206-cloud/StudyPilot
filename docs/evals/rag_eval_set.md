# RAG Evaluation Set

This file will become the fixed test set for evaluating retrieval and answer quality.

## Evaluation Fields

For each case, record:

- Question.
- Source material.
- Expected source chunk or section.
- Expected answer points.
- Actual retrieved chunks.
- Actual answer.
- Citation quality.
- Hallucination risk.
- Notes.
