# Learning Roadmap

The learning method is project-first. Do not wait to finish a full backend course before building.

## Phase 0: Project Foundation

Learn enough to:

- Understand repository structure.
- Maintain project documentation.
- Explain the product goal and architecture.

## Phase 1: Backend Basics

Build:

- FastAPI app.
- PostgreSQL models.
- JWT auth.
- File upload.
- Docker Compose.

Learn:

- FastAPI route design.
- Pydantic schemas.
- SQL basics.
- Backend error handling.

## Phase 2: RAG

Build:

- Document parsing.
- Chunking.
- Embeddings.
- Vector retrieval.
- Cited answers.

Learn:

- Retrieval tradeoffs.
- Context windows.
- Prompt constraints.
- Citation and refusal design.

## Phase 3: Learning Product

Build:

- Study plans.
- Quiz generation.
- Answer grading.
- Wrong-answer review.

Learn:

- Data modeling for workflows.
- Structured AI outputs.
- User progress tracking.

## Phase 4: Agent Orchestration

Build:

- LangGraph workflows.
- Router node.
- Specialized agent nodes.
- AgentRun traces.

Learn:

- State machines.
- Multi-agent boundaries.
- Fallback and retry.
- Cost and latency control.

## Phase 5: Portfolio Polish

Build:

- README.
- Demo screenshots.
- Evaluation report.
- Tests.
- Deployment notes.

Learn:

- How to explain technical decisions.
- How to prepare for interview deep dives.
