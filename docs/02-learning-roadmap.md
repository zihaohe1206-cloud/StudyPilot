# 学习路线

学习方式是项目优先。不要等完整学完后端课程再开始做。

## Phase 0：项目基础

做到：

- 理解仓库结构。
- 维护项目文档。
- 能讲清产品目标和技术架构。

## Phase 1：后端基础

要做：

- FastAPI 应用。
- PostgreSQL 模型。
- JWT 登录鉴权。
- 文件上传。
- Docker Compose。

要学：

- FastAPI 路由设计。
- Pydantic schema。
- SQL 基础。
- 后端错误处理。

## Phase 2：RAG

要做：

- 文档解析。
- 文本切分。
- embedding。
- 向量检索。
- 带引用回答。

要学：

- 检索策略取舍。
- 上下文窗口。
- Prompt 约束。
- 引用和拒答设计。

## Phase 3：学习产品闭环

要做：

- 学习计划。
- 测验生成。
- 答案批改。
- 错题复习。

要学：

- 工作流数据建模。
- AI 结构化输出。
- 用户学习进度跟踪。

## Phase 4：Agent 编排

要做：

- LangGraph 工作流。
- Router 节点。
- 专用 Agent 节点。
- AgentRun 轨迹。

要学：

- 状态机。
- 多 Agent 边界。
- 失败兜底和重试。
- 成本和延迟控制。

## Phase 5：作品集打磨

要做：

- README。
- 演示截图。
- 评估报告。
- 测试。
- 部署说明。

要学：

- 如何解释技术决策。
- 如何准备面试深挖。
