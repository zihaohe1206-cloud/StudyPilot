# ADR-0005：项目最终必须提交到 GitHub

日期：2026-07-09

## 状态

已接受

## 背景

StudyPilot 的目标不只是学习，而是形成可以写进简历、经得起面试深挖的作品集项目。仅有本地代码或零散文档，不利于向招聘方证明项目真实性和工程过程。

## 决策

StudyPilot 最终必须提交到 GitHub。

阶段性要求：

- 本地开发必须保持清晰 git 提交历史。
- 每个阶段完成后都要有语义清楚的 commit。
- 在合适时机创建 GitHub 远程仓库并推送。
- 最终仓库需要包含代码、文档、启动说明、截图或 demo、RAG 评估结果和简历亮点说明。
- 仓库可以先私有，但最终应具备公开展示的质量。

## 理由

- GitHub 仓库是简历项目最直接的证明材料。
- 提交历史可以展示项目不是临时拼凑的。
- README、文档和评估结果能帮助面试官快速理解项目深度。
- 远程仓库方便跨设备、跨 AI 窗口和后续部署协作。

## 影响

正向影响：

- 项目更适合作为作品集展示。
- 开发过程更可追踪。
- 面试时可以直接指向代码、文档和提交记录。

取舍：

- 需要更注意不要提交密钥、`.env`、个人隐私资料或大文件。
- 需要在公开前整理 README、截图、示例数据和敏感信息。
