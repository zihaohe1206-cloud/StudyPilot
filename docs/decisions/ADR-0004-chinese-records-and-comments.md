# ADR-0004：项目记录和代码注释默认使用中文

日期：2026-07-09

## 状态

已接受

## 背景

StudyPilot 是开发者自己的学习和作品集项目。文档、开发日志、会话摘要和面试准备材料主要服务于个人复盘、跨窗口交接和中文面试表达。

## 决策

项目记录默认使用中文：

- README、设计文档、开发日志、会话摘要、ADR 默认中文。
- 代码注释默认中文，但只在解释复杂逻辑、关键约束或技术取舍时写。
- 变量名、函数名、类名、API 路径、框架名、库名、数据库表字段等仍使用英文。
- 面向外部开源或英文简历的材料，可以后续单独补英文版本。

## 理由

- 中文记录更适合学习复盘和长期维护。
- 新 AI 窗口更容易理解用户真实上下文。
- 面试深挖材料可以直接复用为中文表达。
- 保留英文代码标识符，避免脱离主流工程习惯。

## 影响

正向影响：

- 学习记录更容易坚持。
- 决策和问题复盘更自然。
- 面试准备更直接。

取舍：

- 如果未来要面向英文招聘或开源展示，需要额外准备英文 README 或英文项目摘要。
