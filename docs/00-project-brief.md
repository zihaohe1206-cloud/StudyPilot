# 项目简介

## 一句话说明

StudyPilot 是一个基于 RAG 和多 Agent 工作流的个人学习助理，用来帮助用户从自己的学习资料中学习、提问、测验和复习。

## 目标岗位

AI 应用开发、AI Agent 开发，或从前端转向后端 + AI 工程的岗位。

## 为什么做这个项目

这个项目可以把你的前端优势和需要补的后端/AI 能力结合起来：

- 后端 API 和数据建模。
- 文件导入和异步处理。
- RAG 的引用、拒答和评估。
- 基于显式状态和路由的多 Agent 编排。
- 工程文档和技术决策记录。

## MVP

MVP 应该允许用户：

1. 登录。
2. 上传学习资料。
3. 基于资料提问。
4. 获得带引用的回答。
5. 生成简单学习计划。
6. 生成测验题并作答。

## 作品集目标

这个项目要容易演示、容易讲清楚，并且不能被面试官一眼看成“只是套了一个 API”。

最终项目必须提交到 GitHub。GitHub 仓库要能展示代码、文档、提交历史、运行方式、截图或 demo，以及 RAG/Agent 的关键实现证据。
